# 모션 단축키 1.0

웹캠으로 손동작을 인식해 macOS 앱, 커서, 가상 키보드를 제어하는 Electron 앱입니다. 카메라 영상과 손 랜드마크는 기기 안에서만 처리하며 서버로 전송하거나 저장하지 않습니다.

![모션 단축키 파이프라인](public/assets/motion-shortcut-pipeline.png)

## 설치 파일로 실행

`release` 폴더에서 아래 파일을 전달하면 됩니다.

- `Motion-Shortcut-1.0.0-arm64.dmg`: Apple Silicon Mac 설치용
- `Motion-Shortcut-1.0.0-arm64.zip`: 압축 배포용

처음 실행할 때 개발자 공증 경고가 표시되면 Finder의 앱을 우클릭하고 **열기 → 열기**를 선택합니다. 이후 다음 권한을 허용합니다.

1. **카메라**: 시스템 설정 → 개인정보 보호 및 보안 → 카메라 → 모션 단축키
2. **손쉬운 사용**: 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용 → 모션 단축키

권한을 바꾼 뒤에는 앱을 완전히 종료했다가 다시 실행합니다. 이 배포본은 Apple Silicon(M1 이상) Mac용입니다.

## 사용법

| 동작                            | 기능                  |
| ------------------------------- | --------------------- |
| 사용자가 선택한 손모양 1.5초    | 연결한 macOS 앱 열기  |
| 전화 모양 1.5초                 | 모션 인식 ON/OFF      |
| 양손 검지 X 2초                 | 커서 제어 ON/OFF      |
| 오른손 검지·중지 붙여 이동      | 커서 이동             |
| 왼손 펼치기 후 3초 안에 주먹    | 클릭                  |
| 왼손 검지·중지·약지 1.5초       | 가상 키보드 열기/닫기 |
| 키보드 위 양손 손가락으로 타건  | 8손가락으로 키 입력   |
| 키보드 Space 위에서 엄지로 타건 | 공백 입력             |

기본 앱 연결은 비어 있습니다. `+ 실행할 앱 선택`에서 원하는 `.app`을 고른 뒤 검지, V 사인, 오른손 세 손가락, 손바닥, 주먹, 검지·새끼손가락, 엄지 위, L 모양, 핀치, OK 사인, 좌우 기울이기 중 하나를 연결할 수 있습니다. 같은 모션은 두 앱에 중복 연결되지 않습니다.

가상 키보드를 처음 열면 약 13초 동안 검지·중지·약지·새끼손가락·엄지 순으로 개인별 눌림 깊이를 보정합니다. 각 단계에서 안내된 손가락을 편하게 둔 뒤 2~3번 아래로 눌러 주세요. 보정값은 이 Mac에 저장되며 이후 키보드는 투명 모드로 열립니다. 상단의 **다시 보정**으로 언제든 초기화할 수 있습니다.

가상 키보드를 열기 전에 메모나 브라우저 입력창처럼 실제로 입력할 곳에 커서를 놓으세요. 키보드가 열리면 macOS 입력 소스를 두벌식 한글로 자동 전환하며, 닫으면 원래 입력 소스로 돌아갑니다. 데스크톱 손 팻은 키보드 위로 이동하고, 닫으면 이전 표시 모드로 복귀합니다. 일반 키는 양손의 검지·중지·약지·새끼손가락 8개로 입력하며, 양쪽 엄지는 Space에서만 작동합니다.

## 개발

필요 환경: Node.js 20 이상, macOS, Xcode Command Line Tools

```bash
npm install
npm run dev:electron
```

검증:

```bash
npm run lint
npm test
npm run build
```

Apple Silicon 배포본 생성:

```bash
sh scripts/build-icon.sh
npm run dist:mac
```

배포 결과는 `release` 폴더에 생성됩니다. Apple 개발자 인증서가 없는 로컬 배포본이므로 공증은 포함되지 않습니다.
